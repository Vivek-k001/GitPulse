# GitPulse

GitPulse is a fast, client-side repository inspector and sparse folder downloader for GitHub.

---

## Features

- **Folder Downloader**: Download any single directory from a repository as a `.zip` archive directly in the browser without cloning the full repository.
- **Codebase Galaxy**: 3D language distribution view powered by Three.js (Sphere, Spiral, and Ring projections).
- **Commit Activity Heatmap**: 24×7 hourly commit punchcard with hover stats.
- **Contributor Graph**: Force-directed network graph of repository contributors.
- **Recent Activity**: Latest commits feed with links and short SHAs.
- **Zero Configuration**: Runs entirely client-side using public GitHub endpoints.
